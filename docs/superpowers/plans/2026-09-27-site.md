# Site da Floresta dos Bichinhos — plano

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Passos com `- [ ]`.

**Goal:** página única no estilo Pok Pok (mockup aprovado em `docs/mockup.jpg`), pt-BR e it,
publicada no GitHub Pages a partir da `main`.

**Architecture:** HTML + CSS + JS estático, sem build. `js/strings.js` guarda os textos por
idioma; `js/app.js` aplica idioma, links "em breve", carrossel e animações. Arte oficial dos
personagens e prints vêm do site antigo e do jogo; ícones e decoração vêm do ChatGPT.

**Spec:** `docs/superpowers/specs/2026-09-27-site-design.md`

## Global Constraints

- Repositório: `~/Games/floresta-dos-bichinhos-site` ↔ `lucassdoro/floresta-dos-bichinhos-site` (público).
- Toda mudança por issue → branch `tipo/N-descricao` → PR com `Closes #N`. Merge só com pedido.
- Commits sem coautor, sem "Generated with".
- Sem scripts/fontes/analytics de terceiros: fontes (Baloo 2, Nunito) servidas do repo.
- Todo texto visível com `data-i18n` e presente em **todos** os idiomas de `STRINGS`.
- `prefers-reduced-motion` desliga carrossel automático, flutuação e fades.
- Celular: gutter 16 px, sem rolagem horizontal em 390 px.
- Fonte original do site antigo: `~/Games/floresta-dos-bichinhos-old/site/floresta-de-bichinhos/`.
